PART I — COMBINED INDUSTRIAL CHALLENGE QUERIES

Task 59: Display all Active employees from Pune or Mumbai who belong to the IT or Sales department, earn between 40000 and 70000, and joined after '2025-01-01'.

WHERE (city = 'Pune' OR city = 'Mumbai')
  AND department IN ('IT', 'Sales')
  AND salary BETWEEN 40000 AND 70000
  AND joining_date > '2025-01-01';

Task 60: Display all employees whose name begins with S or R, whose email is NOT NULL, whose status is Active, and whose city is IN ('Pune', 'Nashik').
SELECT * FROM employees
WHERE (employee_name LIKE 'S%' OR employee_name LIKE 'R%')
  AND email IS NOT NULL
  AND status = 'Active'
  AND city IN ('Pune', 'Nashik');

IMPORTANT SQL RULES

1. String and date values must be enclosed in single quotes.
   Example: city = 'Pune'
   Example: joining_date = '2026-01-10'

2. Numeric values normally do not need quotes.
   Example: salary > 40000

3. Never use = NULL.
   Correct:
   email IS NULL
   email IS NOT NULL

4. When combining AND and OR, use parentheses to make the intended condition clear.

5. BETWEEN is inclusive, meaning the starting and ending values are included.

6. LIKE uses:
   % = any number of characters
   _ = exactly one character

7. IN is used to match a value against a list.
   Example:
   department IN ('IT', 'HR', 'Sales')

8. NOT IN excludes all values listed inside the brackets.
